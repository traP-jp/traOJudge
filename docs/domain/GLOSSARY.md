# traOJudge の用語

作問、提出、ジャッジ実行の間で共有する概念を定義する。要求仕様と各分野の設計では、この用語を使う。

## ジャッジ

**ジャッジ定義**:
問題をどう採点するかを定める再利用可能な定義。処理の依存関係や実行条件を持ち、個別の提出内容は含まない。
_Avoid_: 問題定義（問題文なども含む概念と混同しやすい）

**ジャッジ実行要求**:
一回のジャッジ実行を依頼する情報。使用するジャッジ定義、提出固有の入力、実行を識別する情報からなる。
_Avoid_: ジャッジ定義（提出固有の情報を含む要求の意味では使わない）

**実行手順**:
ジャッジ定義に提出固有の入力を適用し、その一回の実行内容を具体化した手順。
_Avoid_: ジャッジ実行要求（入力を受け取った段階と、具体化した内容を区別する）
