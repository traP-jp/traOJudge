# traOJudge の用語

作問、提出、ジャッジ実行の間で共有する概念を定義する。要求仕様と各分野の設計では、この用語を使う。

## ジャッジ

**ジャッジ制御**:
ジャッジ定義と提出固有の入力から実行手順を具体化し、DAG の依存関係に従って処理を進め、各処理の結果をジャッジ結果へまとめること。
_Avoid_: ジャッジ本体（実行環境の提供や個別プログラムの実行と混同しやすい）

**ジャッジ定義**:
問題をどう採点するかを定める再利用可能な定義。処理の依存関係や実行条件を持ち、個別の提出内容は含まない。
_Avoid_: 問題定義（問題文なども含む概念と混同しやすい）

**ジャッジ実行要求**:
一回のジャッジ実行を依頼する情報。使用するジャッジ定義、提出固有の入力、実行を識別する情報からなる。
_Avoid_: ジャッジ定義（提出固有の情報を含む要求の意味では使わない）

**ノード実行要求**:
DAG の実行ノード1つの処理を依頼する情報。そのノードの入力・実行条件と、結果を対応付けるための識別情報からなる。
_Avoid_: ジャッジ実行要求（ジャッジ全体への依頼と、個別ノードへの依頼を区別する）

**実行手順**:
ジャッジ定義に提出固有の入力を適用し、その一回の実行内容を具体化した手順。
_Avoid_: ジャッジ実行要求（入力を受け取った段階と、具体化した内容を区別する）

## 解説

**解説の投稿者**:
その解説を最初に投稿した利用者。後から別の人が編集を担当しても、投稿者は変わらない。
_Avoid_: 解説の編集担当（投稿した人を指す意味では使わない）

**解説の編集担当**:
特定の解説の内容を編集する担当者。投稿者と同じ人の場合も、別の人の場合もある。
_Avoid_: 解説の投稿者（担当を任された人を指す意味では使わない）
