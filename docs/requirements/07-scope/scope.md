# スコープ

## 対象

- 一般公開、公開情報の閲覧、承認不要の利用者登録。
- 問題・テストケース・judge-definition の作成と管理、共同作問、公開範囲の管理。
- CLIによる問題登録、そのためのクライアント機能とCLI専用API。
- 提出、ジャッジ、結果の閲覧、再ジャッジ。
- 通常コンテストと virtual-contest の作成・運営・参加。
- コンテストの得点計算、順位、Clar。
- 解説の投稿・編集。
- [ロール定義](../../domain/role.md)に記載された各ロールと操作権限。
- 上記を支える認証、DB、ファイル保管、キュー、メール送信、運用基盤。

## 対象外

- パスワードによるメール認証、およびそのパスワードの再設定機能。メール認証にはマジックリンクを使う。
- メール配送失敗への専用ハンドリングと、アプリケーションによる自動再試行。利用者の再送要求で対応する。
- 得点と選択したタイブレーク値が同じ場合に、最後の得点更新時刻でさらに比較する処理。
