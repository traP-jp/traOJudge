# 製品機能

| 機能群 | 内容 | 主な担当要素 |
| --- | --- | --- |
| 利用者・権限 | 自己登録、認証、ロールの付与・剥奪、操作権限の確認 | 利用者・認証・権限 |
| 作問 | 問題、テストケース、judge-definition、共同作業者、公開範囲の管理 | 問題・作問・解説、ファイル保管 |
| 提出・採点 | ソース提出、ジャッジ依頼、得点と判定の記録・閲覧 | 提出・ジャッジ管理、ジャッジ実行基盤 |
| 再ジャッジ | 問題・コンテスト単位の権限に応じた再実行 | 提出・ジャッジ管理 |
| コンテスト | 通常・バーチャルコンテストの作成、問題の紐付け、開催ルール・時間の設定、参加 | コンテスト・順位 |
| 得点・順位 | 各問題の最高得点の合計、同得点時の比較方式の選択 | コンテスト・順位 |
| Clar | 参加者の問い合わせと運営側の回答 | コンテスト・順位 |
| 解説 | standard-userによる投稿と、投稿者による編集 | 問題・作問・解説 |
| メール認証 | マジックリンクの要求・送信とリンクによる認証 | 利用者・認証・権限、メール送信 |

操作権限は[ロール定義](../../domain/role.md)、確定した振る舞いは[機能要求](../14-specified-requirements/02-functions/functions.md)を参照する。
