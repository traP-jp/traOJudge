# 制限事項

## 構成上の方針

- WebUI は neoShowcase、API・DB・ジャッジ基盤などは AWS に配置する。
- 外部クラウド側の構成要素は同じクラウド事業者にまとめる。
- ファイル保管には S3、ジャッジ要求・結果キューには SQS を採用する方針とする。
- DB は PostgreSQL 互換を優先する。RDSなどの具体的な提供サービスは未決である。
- 基盤を後から差し替えられるようにする。
