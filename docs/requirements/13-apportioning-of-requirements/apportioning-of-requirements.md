# 要求事項の割り当て

要素ごとの主な責務を以下に割り当てる。この分割は、個別のサービス・プロセス・インスタンスを要求するものではない。

## 担当分野

| 分野 | 担当範囲 |
| --- | --- |
| UI | WebUIの画面と利用者操作 |
| Back | WebUI等のAPIとCLI専用API、サービス側の機能・権限・データ、実行依頼、作問者の登録情報に基づくノード結果の解釈と反映 |
| Judge | SQSとS3を使ったジャッジ実行、実行環境、ノード単位の結果報告。DBへの直接アクセスは行わない |
| CLI | 問題登録などをコマンドラインから実行し、DAG・実行環境のメタデータと必要なファイル集合を提供するクライアント |
| インフラ | 配置、DB・ストレージ・キューなどの提供基盤と運用 |

## 要素への割り当て

| 要素 | 割り当てる責務 | 関連する機能要求 |
| --- | --- | --- |
| WebUI | 閲覧・登録・作問・提出・コンテスト参加／運営の画面。提出ソースは署名付きURLでS3へ直接転送 | REQ-PUBLIC-01、REQ-CONTENT-01、REQ-CONTEST-01、REQ-FILE-02 |
| API | WebUI等のAPIとCLI専用APIによる操作受付、入力と権限の確認を各担当へつなぐ、処理の依頼と結果の返却 | 各機能要求の外部受付、REQ-CLI-02 |
| 利用者・認証・権限 | 自己登録、基本ロール、マジックリンク認証、開発者トークンの発行・失効、操作権限 | REQ-REGISTER-01、REQ-ROLE-01、REQ-AUTH-01、REQ-CLI-03 |
| 問題・作問・解説 | 問題・テストケース・judge-definition・解説・共同作業の管理 | REQ-CONTENT-01、REQ-ROLE-01 |
| コンテスト・順位 | 通常／virtualの運営・参加・Clar・得点計算と順位 | REQ-CONTEST-01、REQ-SCORE-01〜04 |
| 提出・ジャッジ管理 | Backによる提出確定・実行IDの発行、固定した定義と提出固有入力の受け渡し、提出記録、作問者の登録情報に基づくノード結果の解釈、重複を二重計上しない結果反映、再ジャッジの管理 | REQ-JUDGE-01〜09、REQ-FILE-01〜02 |
| ジャッジ実行基盤 | SQSからの要求取得、定義と入力からの実行手順の具体化、自身の実行基盤の権限でS3からファイルを取得して実行、同じ実行IDを付けたノード単位の結果報告 | REQ-JUDGE-01〜04、REQ-JUDGE-06〜09、REQ-SCORE-01 |
| DB | 構造化データの永続化。提出ソース本体は含まない | REQ-FILE-01と各機能の保存 |
| ファイル保管 | 提出ソースと作問ファイルの実体を保存・提供 | REQ-FILE-01〜02 |
| ジョブキュー | 要求と結果を非同期に受け渡す | REQ-JUDGE-01 |
| メール送信 | 送信キューから要求を受け取りマジックリンクを配送 | REQ-MAIL-01 |
| CLI | メタデータと必要なファイル集合を用意し、専用APIと署名付きURLで登録・アップロードしてAPIへ完了通知 | REQ-CLI-01〜05、REQ-CONTENT-01 |

機能要求の本文は[機能](../14-specified-requirements/02-functions/functions.md)を参照する。

## 複数分野で決める境界

以下は全体の要件整理で優先する項目である。各分野の内部実装とは分けて扱う。

| 関係する分野 | 決める内容 |
| --- | --- |
| UI・CLI・Back | WebUI等のAPIとCLI専用APIそれぞれの操作範囲、認証・権限、ファイル登録の責任分担 |
| CLI・Back・Judge | [問題登録・ジャッジ実行の受け渡し仕様](../14-specified-requirements/01-external-interfaces/problem-registration-contract.md)の形式・変換境界、実行環境・ファイル参照、検証、互換性 |
| Back・Judge | 使用版を固定した実行要求と結果の契約、実行の識別、再ジャッジと結果反映の責任 |
| Back・インフラ | データとファイルの所有・保存、キューの契約、基盤の交換点 |
| 全分野 | 共有する識別子・用語、契約の変更・互換性、結合時の確認責任 |
