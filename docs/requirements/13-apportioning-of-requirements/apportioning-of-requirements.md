# 要求事項の割り当て

要素ごとの主な責務を以下に割り当てる。この分割は、個別のサービス・プロセス・インスタンスを要求するものではない。

| 要素 | 割り当てる責務 | 関連する機能要求 |
| --- | --- | --- |
| WebUI | 閲覧・登録・作問・提出・コンテスト参加／運営の操作画面 | REQ-PUBLIC-01、REQ-CONTENT-01、REQ-CONTEST-01 |
| API | 公開操作の受付、入力と権限の確認を各担当へつなぐ、処理の依頼と結果の返却 | 各機能要求の外部受付 |
| 利用者・認証・権限 | 自己登録、基本ロール、マジックリンク認証、操作権限 | REQ-REGISTER-01、REQ-ROLE-01、REQ-AUTH-01 |
| 問題・作問・解説 | 問題・テストケース・judge-definition・解説・共同作業の管理 | REQ-CONTENT-01、REQ-ROLE-01 |
| コンテスト・順位 | 通常／virtualの運営・参加・Clar・得点計算と順位 | REQ-CONTEST-01、REQ-SCORE-01〜04 |
| 提出・ジャッジ管理 | 提出記録、実行依頼、結果反映、再ジャッジの管理 | REQ-JUDGE-01、REQ-FILE-01 |
| ジャッジ実行基盤 | ファイル取得、プログラム実行、判定・得点の報告 | REQ-JUDGE-01、REQ-SCORE-01 |
| DB | 構造化データの永続化。提出ソース本体は含まない | REQ-FILE-01と各機能の保存 |
| ファイル保管 | 提出ソースと作問ファイルの実体を保存・提供 | REQ-FILE-01 |
| ジョブキュー | 要求と結果を非同期に受け渡す | REQ-JUDGE-01 |
| メール送信 | 送信キューから要求を受け取りマジックリンクを配送 | REQ-MAIL-01 |
| 作問クライアント | Writerによるファイル登録操作 | REQ-CONTENT-01 |

機能要求の本文は[機能](../14-specified-requirements/02-functions/functions.md)を参照する。
