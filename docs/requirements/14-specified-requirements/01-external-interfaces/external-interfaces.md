# 外部インターフェース

## 接続境界

| 境界 | 目的・受け渡す情報 | 決定状況 |
| --- | --- | --- |
| WebUI・外部クライアント ↔ API | 利用者操作、提出、閲覧、管理操作 | 既存OpenAPIを資料とし、今回の変更を反映する |
| 作問クライアント ↔ API・ファイル保管 | 作問ファイルの登録、更新開始・完了、ファイル転送 | 既存の署名付きアップロード方式を資料とする |
| API ↔ DB | 構造化データの読み書き | PostgreSQL互換を優先 |
| API → ジャッジ要求キュー | 実行する提出・問題・必要ファイルなどの参照 | メッセージ形式はTODO |
| Runner → ジャッジ結果キュー | 実行を識別する情報、判定、得点など | メッセージ形式はTODO |
| 結果反映処理 ↔ DB | 実行結果と提出の現在状態の更新 | 更新契約はTODO |
| API → メールキュー → 送信処理 | 宛先とマジックリンク送信に必要な情報 | 形式・配送サービスはTODO |
| 認証機能 ↔ 外部認証先 | 認可・利用者情報・アカウント対応付け | 採用範囲・責任境界はTODO |

関連資料は[参照文献](../../04-references/references.md)にまとめる。
