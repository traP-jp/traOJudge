# ユーザビリティ要求

WebUIは一般公開の利用者と、ロールに応じた作問者・コンテスト運営者の操作を扱う。登録直後に基本機能を利用できることと、メール認証でパスワードを要求しないことは機能要求に従う。

マジックリンクが届かない場合、利用者が再度送信を要求する運用とする。配送結果を自動回復する機能は要求しない。

## 提出してから結果を待つ間

ジャッジ中に、完了したテストケース数を順次表示する。不正解や時間切れも、そのケースの判定が得られたなら完了として数え、残りのケースをすべて実行する。全ケースの判定完了と、最終結果・得点の確定を区別する。

表示する状態、再接続や再採点時の振る舞いの案は[結果を待つシナリオ](../../scenarios/submissions/watch-judging.md)に記す。完了数を表示することは確定済みであり、総数・ケースごとの判定・途中得点をどこまで併記するかは未決。
