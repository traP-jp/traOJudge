# ユーザビリティ要求

WebUIは一般公開の利用者と、ロールに応じた作問者・コンテスト運営者の操作を扱う。登録直後に基本機能を利用できることと、メール認証でパスワードを要求しないことは機能要求に従う。

マジックリンクが届かない場合、利用者が再度送信を要求する運用とする。配送結果を自動回復する機能は要求しない。
