# 性能要求

一般公開と通常・バーチャルコンテストを対象とするため、平常時とコンテスト開催時の負荷を分けて定義する。現時点で性能の数値目標は確定していない。

| 対象 | 未決事項 |
| --- | --- |
| 閲覧・API操作 | TODO PERF-01: 同時利用者数、要求数、応答時間の目標と測定条件を決める |

| ジャッジ | TODO PERF-03: 同時実行数、待ち時間、処理時間、混雑時の扱いを決める |

| メール送信 | TODO PERF-06: 送信要求の受付・配送までの目標時間と要求頻度の条件を決める |
| ジャッジの途中表示 | TODO PERF-07: ケース判定完了から画面反映までの遅延、同時閲覧数、ケース数・更新量、取得・配信量、保存期間、混雑・一括再採点時の条件を決める |

数値が未決のまま、インスタンス種別や台数を性能要求の代わりに固定しない。[進捗表示の制約](../../submission-progress-constraints.md)に、表示の要望と容量・遅延に効く項目を対応付ける。
