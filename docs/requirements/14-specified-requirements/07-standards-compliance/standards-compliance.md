# 標準への準拠

[CCS Specifications 2026-01](https://ccs-specs.icpc.io/2026-01/)をコンテスト制御の参考資料とする。特に問題ごとのペナルティ時間とその合計の定義を参照する。

本システムのICPC形式・AtCoder形式は、同得点時の比較方式の名称である。コンテスト得点は両方式とも各問題の最高得点の合計であり、CCSのpass-fail方式やWorld Finalsの表彰・順位規則全体への準拠を意味しない。

既存のOpenAPIはインターフェース記述の資料とし、マジックリンク方式などの確定事項を反映する必要がある。
