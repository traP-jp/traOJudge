## PoC の到達点の提案

作問者 CLI で1問を登録し、WebUI から提出して、ジャッジ結果を表示する。

1. CLI が問題文・DAG・必要ファイル・使用する実行環境の指定を用意する。
2. B2 が認証・権限を確認し、B4 の署名付きURLでCLIが直接転送する。完了確認後、B3 に使用可能な問題版を保存する。
3. UI が問題・言語を取得し、B4 に提出ソースを直接転送する。B2 が提出を確定する。
4. B2 が問題版と実行 ID を固定してDAGを解決し、実行可能になった実行ノードを1つずつB5経由でB6へ依頼する。
5. B6 がB7の実行環境で1ノードを処理し、B5へ結果を返す。B2が結果を受理して後続ノードを選び、B3に進捗・結果を保存する。
6. UI がB2から結果を取得・表示する。

最初は単純な加算問題、1言語、1ファイル提出を候補とする。コンテスト・順位・Clar・解説・共同作問・多言語・対戦型は、最初の経路の後に扱う提案とする。これらは引き続き[リリース要求](07-scope/scope.md)に含まれる。

| --- | --- | --- | --- |
| F: WebUI | 共有OpenAPIからの型生成、問題表示・直接転送・提出確定・結果表示 | B2/B4のモックで1問の提出→結果表示が動く | HTTP契約・直接転送のサンプル |
