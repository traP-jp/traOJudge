# 手元の作問ツールを使えるようにする・使えなくする

[シナリオの一覧へ](../../mutation-scenarios.md)

## したいこと

作問者が、手元の作問ツールに設定するための認証情報を発行する。使わなくなったものや、漏れたおそれがあるものは停止する。

## 始める前

自分の名前でログインしていること。問題を登録するには、その問題を編集できる立場でもあること。

## 流れ

```mermaid
flowchart TD
    A["作問ツール用の認証情報を発行する"] --> B(["発行できた"])
    B --> C["その場で表示された文字列を控え、作問ツールに設定する"]
    C --> D(["作問ツールから自分の名前で操作できた"])
    D --> E["使わなくなった認証情報を停止する"]
    E --> F(["その認証情報では操作できなくなった"])
```

## できたと言えること

- 発行した本人が作問ツールに設定できる。秘密の文字列は発行したときだけ表示する。
- ツールからも、その利用者に許されている操作だけができる。
- 停止したものや期限が切れたものでは操作できない。

## まだ決めること

- 期限や使える操作の範囲を利用者が選べるか。
- すでに始めている操作の途中で停止した場合、どこまで続けられるか。
