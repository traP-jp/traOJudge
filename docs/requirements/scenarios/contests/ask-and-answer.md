# 大会について質問し、回答する

[シナリオの一覧へ](../../mutation-scenarios.md)

## したいこと

大会の参加者が、問題文や大会の進め方について質問する。運営する人がその質問に答え、質問した人が回答を確認できるようにする。

## 誰が、誰に、何をしてよいか

| 操作 | 誰が | 誰に／何に・範囲 |
| --- | --- | --- |
| 通常の大会に質問する（C3-01） | 通常大会Cの contestant | その大会Cに、自分の質問を投稿 |
| 通常の大会の質問に回答する（C3-02） | 通常大会Cの contest-setter | 大会Cに寄せられた参加者の質問 |
| バーチャル大会に質問する（C3-03） | バーチャル大会Vの virtual-contestant | その大会Vに、自分の質問を投稿 |
| バーチャル大会の質問に回答する（C3-04） | バーチャル大会Vの virtual-contest-setter | 大会Vに寄せられた参加者の質問 |

根拠は[ロール定義](../../../domain/role.md)。書かれていない役割の許可は補わない。全操作の対応は[許可条件の一覧](../../permission-operations.md)を参照する。

## 始める前

本人がログインしていること。通常大会への質問はその大会の `contestant`、回答はその大会の `contest-setter` が行う。バーチャル大会への質問はその大会の `virtual-contestant`、回答はその大会の `virtual-contest-setter` が行う。別の大会の参加者・運営担当というだけでは許可しない。

## 流れ

```mermaid
flowchart TD
    A["参加者が質問を書く"] --> B{"今、この人が質問してよいか"}
    B -->|はい| C(["大会への質問を受け付けた"])
    C --> D["運営する人が質問を確かめて回答する"]
    D --> E{"この人が回答してよいか"}
    E -->|はい| F(["その質問への回答が残った"])
    F --> G(["質問した人が回答を確認できる"])
    B -->|いいえ| H["質問できない理由を伝える"]
    E -->|いいえ| I["回答せず、回答できない理由を伝える"]
```

## できたと言えること

- 質問と、その質問への回答が対応して残る。
- 上表の参加者だけが自分の質問を投稿し、その大会の運営担当だけがその参加者に回答できる。
- 大会の責任者や問題の管理担当という役割だけでは、質問に回答できない。
- どの大会でのやり取りなのかが分かる。

## まだ決めること

- 質問と回答を、質問者だけに見せるか、ほかの参加者にも見せるか。
- 質問・回答できる期間と、投稿後の訂正を認めるか。
- 回答が届いたことを、質問した人にどう知らせるか。
