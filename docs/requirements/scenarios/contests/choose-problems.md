# 大会で出す問題を選ぶ・外す

[シナリオの一覧へ](../../mutation-scenarios.md)

## したいこと

大会を運営する人が、その大会で出す問題を選んで追加する。出題を取りやめる問題は、大会から外す。

## 誰が、誰に、何をしてよいか

| 操作 | 誰が | 誰に／何に・範囲 |
| --- | --- | --- |
| 通常の大会に問題を追加する（C2-01） | 通常大会Cの contest-setter | 大会Cに、自身が作成者として記録されている問題Pを、終了時刻より前まで追加 |
| 通常の大会から問題を外す（C2-02） | 通常大会Cの contest-setter | 大会Cに含まれる任意の問題P。自分の問題に限らない |
| バーチャル大会に問題を追加する（C2-03） | バーチャル大会Vの virtual-contest-setter | 大会Vに、公開された問題Pを追加。自分の問題に限らない |
| バーチャル大会から問題を外す（C2-04） | バーチャル大会Vの virtual-contest-setter | 大会Vに含まれる問題P |

根拠は[ロール定義](../../../domain/role.md)。書かれていない役割の許可は補わない。全操作の対応は[許可条件の一覧](../../permission-operations.md)を参照する。

## 始める前

本人がログインし、対象の通常大会の `contest-setter`、またはバーチャル大会の `virtual-contest-setter` を持つこと。通常の大会への追加は自身の問題に限るが、取り外す場合は自分以外の問題でもよい。バーチャル大会への追加は公開問題に限り、取り外しはその大会のvirtual-contest-setterに許可する。両大会とも終了時刻より前まで変更できる。

## 流れ

```mermaid
flowchart TD
    A["対象の大会を選ぶ"] --> B{"問題を追加するか、外すか"}
    B -->|追加する| C["出したい問題を選ぶ"]
    C --> D{"この大会で使える問題か"}
    D -->|はい| E(["大会で出す問題に加わった"])
    D -->|いいえ| F["追加できない理由を伝える"]
    B -->|外す| G["対象の問題を選んで取り外す"]
    G --> GX{"対象大会の運営担当で、終了時刻より前か"}
    GX -->|はい| H(["大会で出す問題から外れた"])
    GX -->|いいえ| F
```

## できたと言えること

- その大会で使ってよい問題を終了時刻より前まで追加・取り外しできる。
- 出題一覧は開始前は運営担当だけが取得でき、開始後は公開大会なら誰でも、非公開大会なら運営担当・参加者が取得できる。
- 大会から外す操作と、元の問題そのものを削除する操作を区別する。
- 変更できない人の操作では、大会の問題構成を変えない。

## まだ決めること

- 追加後に元の問題が更新・非公開化・削除された場合にどうするか。
- どの時点の問題内容を大会で使うか。
