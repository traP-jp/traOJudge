# プロフィールを書き直す

[シナリオの一覧へ](../../mutation-scenarios.md)

## したいこと

利用者が、自己紹介や画面に表示する情報など、自分のプロフィールを変更する。

## 始める前

自分の名前でログインしていること。変更したい項目と、新しく載せたい内容が分かっていること。

## 流れ

```mermaid
flowchart TD
    A["自分のプロフィールで変えたい項目を書き直す"] --> B["保存する"]
    B --> C{"変更してよい項目で、内容にも不備がないか"}
    C -->|はい| D(["プロフィールが書き換わった"])
    C -->|いいえ| E["直す必要があるところを伝える"]
```

## できたと言えること

- 自分が変更してよい項目だけを書き換えられる。
- 保存できた場合は、新しい内容を確認できる。
- 内容に不備があるときは、保存できたように案内しない。

## まだ決めること

- 画面で変更できる項目と、文字数などの制限。
- アイコンを変更するときの操作と、使える画像の条件。
