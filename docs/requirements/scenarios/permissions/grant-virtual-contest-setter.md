# 人に好きな時間に挑戦する大会の運営担当を任せる

[シナリオの一覧へ](../../mutation-scenarios.md) · [仕事を任せる・外す話の一覧](change-permissions.md)

## したいこと

サービス管理者（service-admin）が、選んだバーチャル大会1つについて、登録済みの人に好きな時間に挑戦する大会の運営担当を任せる。

## 誰が、誰に、何をしてよいか

| 確かめること | この操作での条件 |
| --- | --- |
| 誰が | サービス管理者（service-admin） |
| 誰に | 役割を任せたい、登録済みの人 |
| 何について | 選んだバーチャル大会1つ |
| 何をする | 選んだ人に `virtual-contest-setter` を付ける |
| 任せる仕事 | 公開問題の出題追加、ルール・開催時間の変更、提出の閲覧、質問への回答ができる |

根拠は[ロール定義](../../../domain/role.md)の `service-admin`、仕事の範囲は `virtual-contest-setter`。

## 始める前

操作する人がログインしていて、上記の立場を持つこと。対象の人と、対象のバーチャル大会が存在し、どの人のどの範囲を変えるかが決まっていること。

## 流れ

```mermaid
flowchart TD
    A["サービス管理者が対象の人とバーチャル大会を選ぶ"] --> B["好きな時間に挑戦する大会の運営担当を任せるよう頼む"]
    B --> C{"サービス管理者か"}
    C -->|はい| D(["選んだ人に、選んだ範囲の好きな時間に挑戦する大会の運営担当を任せた"])
    C -->|いいえ| E["役割を変えず、変更できない理由を伝える"]
```

## できたと言えること

- 選んだ人に、選んだ範囲の好きな時間に挑戦する大会の運営担当を任せたことが分かる。
- 別の人や、別のバーチャル大会の役割を変えない。
- サービス管理者以外が追加できる役割は、テスト担当と通常の大会の運営担当について明記した場合に限る。
- 通常の大会の運営担当とは異なり、問題のテスト担当と同じ仕事は任せない。

## まだ決めること

- すでに同じ仕事を任せていた人に、もう一度頼まれた場合の扱い。
- 自分自身を対象にする場合の条件と、変更の履歴を誰に見せるか。
