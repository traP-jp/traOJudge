# モックを使った仮ログイン

開発中の画面確認には、モックの固定ユーザーを使う。セットアップと起動は[開発手順](development.md)を参照。

## ログインとログアウト

`http://localhost:5173/login` の「モックでログイン」を押すと、仮の利用者としてログインする。ログアウトはヘッダーのユーザーメニューから行う。

仮ログインは固定トークンを `POST /api/v1/auth/email/verifications` に送り、Cookieを受け取った後、`GET /api/v1/me` で本人情報を取得する。モックはトークンとCookieを確認し、ログアウト時の `DELETE /api/v1/auth/session` でCookieを削除する。

再読み込み時もCookieを使って本人情報を取得する。401は未ログインとして扱い、通信に失敗した場合は「再試行」で確認し直せる。

## 開発中の制約

仮ログインのボタンと処理はViteの開発環境でのみ有効。通常問題の作成・編集も、開発環境でログイン済みの利用者に許可している。

モックは固定の認証情報を使うため、実際の本人確認は行わない。メール・外部サービスによる登録とログイン、認証方法の管理、パスワード再設定の画面は準備中としている。
